# Synthetic GR86 comparison package

This package is a **GR86-inspired engineering fixture**, not a digitized OEM suspension. Toyota-published envelope values are isolated in `vehicle-envelope.json`. CG height, springs, bars, and every suspension hard point are clearly marked synthetic or estimated and remain editable.

The declared production topology is retained: MacPherson strut front and double-wishbone-style multilink rear. No rear-strut substitution is allowed in the completed head-to-head solver. Until the 3D constraint path reports a valid result, UI output must identify any legacy planar/scalar result as provisional.

Public references:

- Toyota GR86 technical specification: https://media.toyota.co.uk/wp-content/uploads/sites/5/pdf/220725M-GR86-Tech-Spec.pdf
- Toyota GR86 vehicle presentation: https://media.toyota.co.uk/toyota-presents-the-new-gr86/
