# Bump Stop Studio preparation checkpoint

Open **Component Designer → Bump curve → Prepare STEP bumper / fixtures…**. The window is modeless; reopening it activates the existing Studio window. It uses the application's shared inspection renderer and navigation.

1. Confirm the source length unit and import a STEP solid. The first supported importer accepts one closed volume with explicit millimetre/metre metadata. Original bytes, units, importer identity and actual CAD-face tags are preserved. Healing/sewing are disabled. Check the displayed CAD dimensions and confirm them.
2. Set the compression frame, free reference length and requested shortening. Frame +Z points from the lower fixture toward the upper fixture; compression drives the upper fixture toward −Z. Changing the frame does not rewrite the source solid.
3. Pick actual CAD faces in the view or the face table and assign their roles. Define platens, annular clearances, optional shaft position/length/radius, gaps/interference, friction, bonded faces and opposing fold surfaces. These are preparation inputs; the worker still has to resolve installation/interference and verify the supported contact recipe.
4. Select a material family/card and record conditions/evidence. TPU 85A/90A/95A are explicit families with print orientation, dimensions, walls/layers and infill representation/settings. They remain **Needs calibration** until compatible fitted data exist. Sparse infill is neither generated by STEP import nor represented by scaling a modulus with infill percentage.
5. Save a preparation recipe. Reopening checks the exact recipe, CAD inspection, source and retained material-evidence identities. Invalid typed drafts are preserved for correction. A documented imported card needs its original matching evidence artifacts and declared use interval; importing it does not establish independent part correlation.

The **Verification** tab reads the separate running numerical benchmark and study. It shows elapsed/budget, RAM, accepted fraction of that benchmark's requested stroke, curve acceptance and log locations. That benchmark is not a solve of the currently open recipe.

This checkpoint does not yet provide production meshing/solve controls, deformation playback, result publication, axisymmetric Studio support or a calibrated material catalog. The Stage 9 folding/contact/sensitivity gates must pass before worker admission and curve publication. Measured CSV curves remain usable through the completed [imported bumper workflow](imported-bumper-workflow.md).

Developer evidence: `artifacts/bump-studio-ui` contains native face-picking/recipe/recovery proof and inspected captures; `artifacts/bump-studio-preparation` contains the focused real STEP-import recipe/inspection fixture. `tools/fea-volume-prepare.py` independently creates a quadratic volume mesh from those exact saved artifacts and retains the CAD-face-to-volume-boundary mapping. This command prepares geometry only and never emits a force curve.
